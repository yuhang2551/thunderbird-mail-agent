# Thunderbird 设置

这里讲怎么把各类邮箱登录进 Thunderbird，以及让它更适合配合 Agent 使用。Agent 能看到的邮件，就是 Thunderbird 里同步下来的邮件。

## 添加邮箱

菜单 **文件 → 新建 → 现有邮件账户**（英文界面是 File → New → Existing Mail Account），填姓名、邮箱地址，密码先空着，点"继续"。

| 邮箱 | 怎么填 |
|---|---|
| **Gmail / Google Workspace** | 自动识别。会弹出 Google 登录页（OAuth2），在里面登录并授权即可 |
| **Outlook.com / Hotmail（个人）** | 自动识别，同样走微软的网页登录 |
| **Microsoft 365 工作或学校邮箱** | 能自动识别就直接用；需要手动填写时见下表 |
| **iCloud** | 先在 Apple 账户网站生成"App 专用密码"，用它当密码 |
| **QQ / 163 / 126 等** | 先在网页版设置里开启 IMAP，生成**授权码**，用授权码当密码 |
| **其他企业邮箱** | 问 IT 要 IMAP / SMTP 服务器地址，或者看邮箱网页版的"客户端设置"说明 |

### Microsoft 365 手动设置

| | 服务器 | 端口 | 加密 | 认证方式 |
|---|---|---|---|---|
| 收件 IMAP | `outlook.office365.com` | 993 | SSL/TLS | OAuth2 |
| 发件 SMTP | `smtp.office365.com` | 587 | STARTTLS | OAuth2 |

- 用户名填完整邮箱地址。
- 认证方式一定要选 **OAuth2**。选"普通密码"会登录失败，微软已经停用了 IMAP 的密码登录。
- 新版 Thunderbird 可能会让你在 **Exchange** 和 **IMAP** 之间选。选 IMAP：本仓库是按 IMAP 测试的。
- 如果登录页提示"需要管理员批准"，说明你的机构不允许 Thunderbird 访问邮箱。这只能找 IT，本方案在这种情况下用不了。

### 系统集成弹窗

第一次启动时，Thunderbird 会问要不要把它设为默认邮件程序，以及要不要让系统搜索（macOS 聚焦 / Windows 搜索）索引邮件。这两项都不影响本方案，可以都不勾，直接跳过。

## 订阅文件夹（机构邮箱一定要做）

Microsoft 365 账户加进来以后，可能只显示收件箱。没有"草稿"文件夹的话，Agent 存不了草稿。

1. 在左侧账户名上点右键 → **订阅**（Subscribe）
2. 勾选 **草稿 / Drafts**、**已发送 / Sent Items**、**垃圾邮件 / Junk Email**、**存档 / Archive**，以及你常用的其他文件夹
3. 点"确定"，等它同步

列表比较长时，勾之前确认勾的是哪一行，滚动时容易点错。

## Gmail 的"所有邮件"

Gmail 的 `[Gmail]/所有邮件`（All Mail）里有你所有邮件的副本，和收件箱是重复的。规则文件让 Agent 只读 INBOX，所以不用管它。不想占硬盘的话，可以在订阅里取消勾选。

## 建议保留的默认设置

- **账户设置 → 同步与存储 → 在此计算机上保留此账户的邮件**：保持开启。邮件存在本地，Agent 读全文更快更稳。
- **账户设置 → 服务器设置 → 每 N 分钟检查新邮件**：保持开启，这样 Agent 看到的是最新的邮件。

## 界面优化

不打算用 Thunderbird 看邮件的话，这一节可以跳过，让它在后台开着就行。想用它看邮件的话，下面几项能让界面清楚很多：

| 调整 | 在哪里 | 效果 |
|---|---|---|
| **表格视图** | 邮件列表上方的"列表显示选项"图标 → 表格视图（Table View） | 一行一封，发件人、标题、时间对齐，比卡片视图更紧凑 |
| **不按会话分组** | 菜单 **查看 → 排序方式 → 不分组**（Unthreaded） | 不再折叠成一串串对话，每封邮件单独一行，新邮件不会被藏起来 |
| **统一文件夹** | 左侧文件夹栏顶部的"⋯" → 文件夹模式 → 勾选 **统一文件夹**（Unified Folders） | 多个邮箱的收件箱合并显示在一个"收件箱"里，同时保留各账户的文件夹 |
| **布局** | 菜单 **查看 → 布局** | "经典"是上列表、下正文；"垂直"是左右三栏，宽屏更合适 |
| **密度和字号** | 菜单 **查看 → 密度 / 字体大小** | 调成"紧凑"能一屏显示更多邮件 |
| **捐款提示条** | 点提示条右边的 × | 关掉后不再显示 |

菜单项的名称可能随 Thunderbird 版本变化，找不到时可以看英文名，或在设置里搜索。
