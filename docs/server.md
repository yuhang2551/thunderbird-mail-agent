# 常开部署：避开"电脑必须开着"

本方案依赖一个正在运行的 Thunderbird。笔记本合上或关机后，Agent 就读不到邮件了。下面三种做法可以让它一直可用，按从简单到复杂排列。

> ⚠️ 本页的方案二、三作者没有完整测试过，按原理和上游文档整理，欢迎反馈。

## 方案一：一台常开的电脑（最简单）

家里的 Mac mini、旧笔记本、台式机都可以。整套东西和 README 里的一样，只是这台电脑不关机。

- **不让它睡眠**：macOS 在 系统设置 → 电池 / 能耗 里打开"显示器关闭时防止自动睡眠"（不同机型名称略有不同）。临时的话可以在终端运行 `caffeinate -s`。
- **开机自动打开 Thunderbird**：系统设置 → 通用 → 登录项 → 添加 Thunderbird。
- **手机上用**：在这台电脑上按 [mobile.md](mobile.md) 的方法二启动 `claude remote-control`，挂在后台即可。

## 方案二：Linux 服务器或 VPS，Agent 也装在上面

Thunderbird 是图形程序，服务器上要给它一个虚拟显示：

1. 装 Thunderbird、Node.js 和虚拟显示（如 Xvfb），或者装一个轻量桌面加 VNC。**第一次登录邮箱需要在浏览器窗口里完成 OAuth**，所以至少第一次要能看到画面（VNC 最方便）。
2. 登录好邮箱、装好扩展后，可以用 `xvfb-run thunderbird` 之类的方式在后台常驻，并配成开机自启（systemd 用户服务）。
3. 在同一台服务器上装 Claude Code 或 Codex CLI，运行本仓库的脚本。bridge 和扩展都只走本机 127.0.0.1，不需要开放任何端口。
4. 用 SSH 加 tmux 登录服务器使用；或者在服务器上运行 `claude remote-control`，从手机连接。

**注意**：
- 邮件会存储在这台服务器上。工作或学校邮箱请先确认机构是否允许把邮件存放在第三方服务器上。
- 服务器的 IP 换了地方，微软或 Google 可能要求重新验证登录。

## 方案三：Thunderbird 在常开电脑上，Agent 在别的电脑上

扩展只监听本机，要让另一台电脑访问，用 **SSH 隧道**（上游作者也推荐这样做）。在 Agent 所在的电脑上运行下面这行，把对方的 8765 端口映射到本机：

```bash
ssh -N -L 8765:127.0.0.1:8765 用户名@常开电脑
```

然后在扩展设置里设一个**固定令牌**（stable token），Agent 用 HTTP 方式连接 `http://127.0.0.1:8765/`（见 [agents.md](agents.md#直接用-http-连接进阶)）。

**不建议**打开扩展的 *Listen on all interfaces*：那是明文 HTTP，令牌和邮件内容会在网络上裸奔，局域网里的任何设备都能尝试连接。如果一定要用，至少只在 Tailscale 这类加密的私有网络里用，并且设置强令牌。
